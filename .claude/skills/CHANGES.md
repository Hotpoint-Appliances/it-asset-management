# Rounded aesthetics to the main ITAM dashboard

- Currently the dashboard layout uses straight lines that separate the main content, one straight line for the top bar and another straight line separating the left desktop sidebar.
- The goal is to shift from this straight line aesthetics to rounded aesthetics for the borders. The rounded borders will be offset abit in the right and bottom, and top if required.
- Your recommendations/critiques on how to achieve this based on the latest UI/UX conventions are highly encouraged.
- Seek clarifications you might have regarding these proposed changes or related areas affected by the proposed changes.
